# 검증 범위

## 자동 시험

`tests/host/run.sh`는 Ubuntu 호스트에서 생산 코드의 navigation/text_edit/imu_math/secret_store와 실제 config.cpp를 컴파일한다. 메모리 경계 검사(ASan/UBSan)를 켠다. 기기/NVS/파일시스템 마운트 API만 시험 대역으로 바꾸며, JSON·암호 알고리즘·파일 저장 로직은 실 코드를 쓴다. 호스트 mbedTLS와 기기 SDK의 차이는 실제 IDF 빌드로 별도 확인한다.

버튼 단일·더블·길게·조합·화면 전환·시간 오버플로·역할 교환·Legacy, ASCII 95개·바이트 정확도·길이/빈값·UTF-8 삭제·Wi-Fi 길이, 회전 4×축 교환×X/Y 반전 32조합·데드존·dt 상한, GCM 왕복/손상/경계·기존 CBC 읽기, 기존 JSON·알 수 없는 필드·쓰기/flush/fsync/close/rename 두 지점 실패·NVS 실패·정상본/백업/임시본 복구를 검사한다.

실행 성공 여부는 해당 소스 SHA의 GitHub Actions 결과와 로그를 따른다. 이 문서의 시험 목록만으로 통과를 주장하지 않는다.

추가 UI 시험은 실제 `text_input.cpp`를 가상 M5 화면/입력과 연결해 ASCII 95개를 버튼 의미 이벤트만으로 입력하고, 페이지 전환·취소 시 출력 불변·숨김·길이 경계·여러행 입력을 실행한다. 네 회전의 두 화면 크기에서 셀/커서 좌표가 화면 범위에 있는지도 검사한다. 이는 실물 글꼴 렌더링·물리 버튼·기울기 방향 시험을 대신하지 않는다.

## 앱별 좌표와 버튼 범위

| 경로 | 적용 |
|---|---|
| 일반 목록·Settings·BIOS 메인·빠른 설정·파일 목록·기호 키보드·부팅 선택 | 공통 버튼 의미와 화면 크기 계산 |
| 시스템 커서·키보드 IMU·Air Mouse | 중립 제거→회전→교환/반전→데드존/평활화 |
| Snake | 공통 IMU 좌표. 실제 조작 방향·체감 회귀 미검증 |
| Cube 시각 데모·수평계·센서 진단·걸음수 | 원래 물리 데이터 경로 유지. 사용자 커서 축 변경으로 물리 진단을 왜곡하지 않음 |
| Tetris·기타 게임 | 기존 물리 버튼 조작 보존, A+B 탈출은 기존 경로. 게임 고유 조작은 Bruce 메뉴 버튼과 구별 |
| IR 화면 | 임시 회전 및 종료 시 원래 회전 복구를 공통 API로 호출 |

## 알려진 제한과 실물 미실행 항목

- **실기기 조작·센서·회전 화면·Wi-Fi 연결·전원 재연결·점수 저장·오디오·IR·백업 복원은 전부 미실행**이다. 단위 시험/빌드가 이를 대신하지 않는다.
- 기본 방향은 기존 absolute rotation=1을 상대 0도로 둔다. 90도 행렬의 물리 부호와 모든 앱의 135×240/240×135 화면 잘림은 실물에서 확인해야 한다. 일부 기존 앱의 고정 레이아웃/앱 전용 입력 경로는 추가 회귀 대상이다.
- upstream RU 배열은 물음표로 손상돼 있다. RU 접근 키는 제한 안내로 남기고, 새 러시아어/한글 입력기는 만들지 않았다.
- 64자리 HEX raw PSK는 현재 설정 버퍼가 64바이트라 지원하지 않는다. 일반 입력은 63바이트까지, 64바이트는 잘라 수용하지 않는다.
- Legacy CBC는 인증이 없어 PKCS7/HEX 검사의 한계가 있다. 새 저장은 인증 GCM이며 기존 암호를 해독하지 못하면 해당 네트워크를 재입력한다.
- 새 설정 세대/checksum은 우발 손상 복구용이며 공격자에 대한 전체 설정 인증은 아니다. 알 수 없는 JSON 필드는 가능한 범위에서 보존한다. 게임 점수·화면 설정 전체 초기화는 하지 않는다.
- 설정 쓰기는 mutex로 직렬화한다. 기존 전역 g_config를 직접 바꾸는 앱 전체를 트랜잭션 모델로 재설계하지는 않았다.
- M5Unified가 제거한 접점 떨림 이후 상태를 의미 이벤트로 처리한다. 실제 버튼 바운스·USB 리셋/다운로드 동작은 기기 검증 대상이다.
